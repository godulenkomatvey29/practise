## Цель работы

Освоить методы разведочного анализа данных, визуализацию распределений, выявление трендов и пропусков.

## Задачи

1. Провести первичный анализ структуры данных.
2. Вычислить основные статистические характеристики.
3. Построить визуализации распределений признаков.
4. Выявить тренды и зависимости между переменными.
5. Обнаружить пропуски и аномалии.

## Данные

`StudentsPerformance.csv` содержит результаты экзаменов 1000 школьников по математике, чтению и письму (`math score`, `reading score`, `writing score`). Кроме баллов, в нём есть сведения об учениках: пол, группа, уровень образования родителей, тип питания и прохождение подготовительного курса.

## Содержание ноутбука

- Первичный анализ структуры: размер, типы данных, категориальные признаки.
- Описательные статистики: среднее, медиана, СКО, квартили, асимметрия, эксцесс.
- Проверка пропусков и дубликатов.
- **Pandas:** столбчатая диаграмма (`parental level of education`), круговая диаграмма (`race/ethnicity`), гистограммы всех числовых столбцов.
- **Matplotlib** (`subplot(32X)`):
  - X=1 — графики cos(2x) и 2cos(x);
  - X=2 — ящик с усами для `math score` и анализ выбросов;
  - X=3 — комбинированный график (столбцы и линия);
  - X=4 — текст;
  - X=5 — 3D-диаграмма рассеяния;
  - X=6 — круговая диаграмма с процентами для юношей.
- **Seaborn:** `pairplot` с гистограммами, `pairplot` с KDE и `hue="gender"`, тепловая карта корреляций.
- Тренды и зависимости: средние баллы по группам.
- Аномалии и выводы.

## Основные выводы

- Пропусков и дубликатов в данных нет.
- Распределения баллов близки к нормальным: средние 66.1 / 69.2 / 68.1, СКО ≈ 15.
- Баллы по предметам сильно коррелируют; наиболее тесная связь у reading и writing (r = 0.955).
- Девушки лучше справляются с чтением и письмом, юноши — с математикой.
- Подготовительный курс и стандартное питание связаны с более высокими баллами.
- По `math score` есть 8 выбросов снизу (минимум 0 баллов). Выбросов сверху нет.
