# Лабораторная работа №5 — Предобработка данных для ML и основы аналитики

Выполнил: Годуленко Матвей, группа ЕТ-213.

## Цель

Изучить масштабирование, кодирование категорий, ColumnTransformer, постановку аналитической задачи и построение выборок без утечки данных.

## Файлы

- Lab05.ipynb — выполненный ноутбук с таблицами, графиками и письменными ответами.
- bank_customers.csv — синтетические данные 800 клиентов; первая ячейка воспроизводит их с seed=42.
- requirements.txt — зависимости для запуска.

## Содержание

1. SMART-цель, декомпозиция и смещения выборки.
2. Типы признаков и выбросы по правилу трёх сигм.
3. MinMaxScaler, StandardScaler и RobustScaler.
4. Label-, One-Hot-, Ordinal- и Frequency-кодирование.
5. ColumnTransformer: разделение train/test до fit.
6. Стратификация и влияние размера выборки на оценку медианы.

## Результаты

Датасет содержит 800 строк и 8 столбцов. Доля Churn — 0,37125. В Income добавлен выброс 5 000 000. Подготовленные выборки имеют размеры (600, 11) и (200, 11).

Доля оттока в выборках по 100 клиентов: случайная — 0,320, стратифицированная — 0,370. СКО оценок медианы Income: около 10 391 для n=20, 3 887 для n=100 и 1 138 для n=500.

Масштабирование не делает распределение нормальным. Итоговый препроцессор обучен только на train. Модель классификации не обучается. Ограничения данных о доходе банка и поддержке разобраны в письменных ответах.

## Запуск

Рекомендуется Python 3.13.

Выполните pip install -r requirements.txt, затем jupyter notebook Lab05.ipynb. Выберите ядро Python с установленными зависимостями и запустите ячейки сверху вниз.

Датасет создаётся первой ячейкой. Все 14 кодовых ячеек уже выполнены, результаты сохранены.
