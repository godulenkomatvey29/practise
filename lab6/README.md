Обработан корпус из 25 отзывов о фильмах. Выполнены очистка и лемматизация, построены мешок слов, униграммы с биграммами и TF-IDF с ограничением словаря. ## Файлы

- `notebook.ipynb` — выполненный отчёт с графиками, таблицами и выводами.
- `data/reviews.csv` — исходные отзывы из задания, не изменены.
- `data/russian_stopwords.txt` — стандартный список 151 русского стоп-слова NLTK (корпус stopwords, https://github.com/nltk/nltk_data). Список сохранён для запуска без скачивания данных. Перед использованием слова лемматизируются так же, как тексты.
- `requirements.txt` — минимальные версии используемых библиотек.

## Запуск

Python 3.10+; работа выполнена на Python 3.13.

```bash
pip install -r requirements.txt
jupyter notebook notebook.ipynb
```

Откройте ядро Python с установленными зависимостями и выполните ячейки сверху вниз. Рабочая папка — `lab6`, путь к корпусу — `data/reviews.csv`. Словари pymorphy3 устанавливаются вместе с пакетом; NLTK-данные при запуске не скачиваются.
