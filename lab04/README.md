# Лабораторная работа №4 — Гипотезы и статистические тесты

Выполнил: Годуленко Матвей, группа ЭТ-213.

## Цель и содержание

Описательная статистика, проверка нормальности и сравнение средних независимых групп:

- Пренатальная диагностика: пропуски, описательные характеристики, ИМТ, гистограммы, критерий Шапиро—Уилка и t-тест Уэлча для мальчиков и девочек.
- Психологи: t-тест Уэлча для сравнения девушек и юношей по результатам тестов.
- Iris: проверка нормальности критерием χ² Пирсона для общей выборки и отдельных видов.

Уровень значимости — 0,05. При p-value < 0,05 нулевая гипотеза отвергается; иначе оснований отвергнуть её недостаточно. Сравнения психологических показателей выполняются без поправки на множественные проверки.

## Файлы

- Lab04.ipynb — ноутбук с кодом и пояснениями; имена переменных записаны латиницей.
- requirements.txt — библиотеки для локального запуска.

Учебные Excel-файлы нужно получить из материалов курса и положить рядом с ноутбуком: «Пренатальная диагностика.xlsx» (лист «исходные данные»), «Психологи.xlsx» и «Iris.xlsx» (лист «Data»).

## Запуск

Установите зависимости командой pip install -r requirements.txt, затем выполните jupyter notebook Lab04.ipynb. Запустите все ячейки сверху вниз.

В JupyterLite загрузите ноутбук и три Excel-файла в одну папку и выберите Python (Pyodide). Первая ячейка устанавливает openpyxl; для первого запуска нужен интернет.

## Основные результаты

В пренатальных данных критерий Шапиро—Уилка отвергает нормальность всех семи показателей. По данным психологов отдельные проверки выявили значимое различие по шкале «экстраверсия — интроверсия» (p ≈ 0,001), средний балл девушек выше. По остальным показателям p ≥ 0,05. Результаты проверки Iris зависят от состава группы и разбиения на интервалы.
