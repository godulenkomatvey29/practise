## Содержание

В работе выполнены:
- формирование и сохранение исходных данных (`online_store_orders.csv`);
- загрузка данных из CSV;
- проверка структуры и качества данных (размер, типы, пропуски);
- выборка и фильтрация (`[[...]]`, `.iloc`, булевы маски);
- расчёт статистик (`describe`, среднее, медиана, `value_counts`);
- создание производного признака `is_high_value`;
- группировка данных по каналам продаж и сортировка;
- формирование аналитического вывода;
- дополнительное задание: гистограмма распределения суммы заказов и анализ влияния выброса.

## Файлы

- `Lab02.ipynb` — ноутбук с кодом, результатами и ответами на контрольные вопросы;
- `online_store_orders.csv` — исходные данные;
- `README.md` — описание работы.
